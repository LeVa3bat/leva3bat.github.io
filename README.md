# Инструкция по запуску сайта «КАПТЁРКА PRO»

Мы создали современный, минималистичный и адаптивный сайт для приложения **«КАПТЁРКА PRO»** в тёмном тактическом стиле (папка `/site/index.html`).

---

## 🚀 Вариант 1. Запуск через GitHub Pages (Бесплатно за 2 минуты, рекомендуется)

1. Зайдите на [github.com](https://github.com) и создайте новый публичный репозиторий (например, `kapterka-app`).
2. Загрузите в него файлы:
   - `index.html` (из папки `site`)
   - `kapterka-app.apk` (ваш собранный APK-файл приложения)
3. Перейдите в репозитории: **Settings** (Настройки) → **Pages**.
4. В поле **Branch** выберите `main` / `root` и нажмите **Save**.
5. Через 30 секунд ваш сайт будет доступен по адресу:  
   `https://ваш-логин.github.io/kapterka-app/`

---

## ⚡ Вариант 2. Запуск через Netlify Drop (Без кода за 1 минуту)

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку `site` (где лежат `index.html` и `kapterka-app.apk`) прямо в окно браузера.
3. Netlify мгновенно выдаст рабочую ссылку (например, `https://kapterka-pro.netlify.app`), которая сразу будет работать во всем мире!

---

## 🌐 Вариант 3. Запуск на любом стандартном хостинге (Beget / Timeweb / Reg.ru)

1. Зайдите в файловый менеджер вашего хостинга в папку сайта (обычно `public_html` или `www`).
2. Загрузите туда файл `index.html` и ваш `.apk` файл.
3. Сайт сразу откроется по вашему домену!
